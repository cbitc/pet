# NNNN · 一句话标题

> 状态：提案 · 类型：特性 · 日期：YYYY-MM-DD · 关联：GitHub #n / `NNNN-slug.md`

---

## 1. 背景与问题

现在为什么要做？谁受影响、影响是什么？用事实描述，不写解决方案。

## 2. 目标与非目标

- **目标**：本次要达成的可观察结果。
- **非目标**：明确不做的事（防止范围蔓延，也让后来者知道这不是遗漏）。

## 3. 验收标准

可被命令、测试或现象验证的条目：

- [ ] `<命令>` 通过 / 现象成立
- [ ] 领域规则在 `tests/domain/` 有用例守护
- [ ] 若涉及外部输入解析，`tests/contracts/` 覆盖坏数据回退

## 4. 方案

技术方案、改动面（哪些层、哪些文件）、风险与回退方式。

## 5. 决策记录

关键取舍与**被否决的备选方案**（尤其是不可逆决策）。格式：

| 决策 | 理由 | 备选（未采用） |
| ---- | ---- | -------------- |

## 6. 执行与结果

实际落地了什么；与方案的偏差；遗留问题与后续 issue 链接。

## 7. 如何验证

```bash
npm run typecheck
npm test
# 涉及壳/渲染时：
npm run smoke
```

## 8. 关联

- 代码：`文件:行号` 或模块
- 全局文档：`../domain.md` / `../architecture.md` / `../conventions.md`
- 其他 issue：`000x-slug.md`
